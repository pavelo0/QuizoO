В результате выполнения курсовой работы было спроектировано и разработано веб-приложение QuizoO — платформа для самостоятельного закрепления знаний, позволяющая создавать учебные модули двух типов, проходить обучение в форматах карточек и викторин, а также отслеживать результаты обучения.

Приложение поддерживает три роли пользователей: гость, пользователь и администратор. Гость может зарегистрироваться, подтвердить email, войти в систему, восстановить пароль и использовать вход через Google OAuth. Пользователь создаёт и редактирует собственные модули, проходит занятия, просматривает статистику и управляет профилем. Администратор получает доступ к панели управления, списку пользователей и списку модулей, а также может выполнять административные действия, например блокировать и разблокировать пользователей.

В рамках проекта реализованы основные функциональные блоки, включающие аутентификацию и управление cookie-сессией на основе JWT, работу с профилем, создание и редактирование учебных модулей, прохождение карточек и квизов, сохранение результатов обучения и административные операции. Функциональная модель приложения соответствует предметной области образовательной платформы и охватывает сценарии работы как обычного пользователя, так и администратора.

База данных приложения спроектирована в реляционной модели на основе Prisma Schema и включает центральные сущности, связанные с пользователями, учебными модулями, карточками, вопросами, вариантами ответов, парами сопоставления и учебными сессиями. Для основных связей между сущностями использованы каскадные удаления, что обеспечивает целостность данных при удалении модулей или пользователей.

Архитектура приложения построена по трёхуровневой клиент-серверной схеме: браузерное SPA, REST API на NestJS и реляционная СУБД PostgreSQL. Развёртывание описано через Docker Compose: сервис PostgreSQL хранит данные, backend выполняет API и миграции Prisma, frontend-builder собирает статические файлы клиентской части, а Nginx выступает единой точкой входа, обеспечивает TLS и проксирование запросов с префиксом /api. Такое решение упрощает сопровождение, изоляцию сервисов и переносимость системы.

В проекте используется единая языковая платформа JavaScript/TypeScript, что позволило согласовать структуру данных и контракт взаимодействия между клиентской и серверной частями. Для реализации клиентской части использованы React 19, Vite 7, React Router, Axios, Redux Toolkit, react-hook-form, Zod и Tailwind CSS. Серверная часть реализована на NestJS 11 с использованием Prisma 6, PostgreSQL 18, JWT, bcrypt, cookie-parser и Nodemailer/SMTP для доставки кодов подтверждения и сброса пароля. Это обеспечило модульность, типобезопасность и удобство дальнейшего развития системы.

Качество разработанного приложения подтверждено ручной проверкой основных пользовательских сценариев и автоматизированными проверками серверной части на Jest. В ходе проверки рассматривались регистрация, вход, работа с профилем, создание модулей, прохождение карточек и квизов, а также административные операции. Дополнительно в документации проекта зафиксированы команды контроля работоспособности инфраструктуры, проверки типов, линтинга и сборки.

Таким образом, поставленные цели курсового проекта достигнуты, а разработанное веб-приложение QuizoO соответствует заявленным функциональным и архитектурным требованиям. Полученный результат может использоваться как готовая основа для дальнейшего развития образовательной платформы и расширения её возможностей.
